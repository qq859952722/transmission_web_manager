# TRWM (Transmission Web Manager) 全面审计报告

> 审计日期：2026-05-26  
> 审计范围：项目全量源代码、设计方案文档、翻译文件  
> 项目版本：1.0.0 (SolidJS 重写版)

---

## 总体评估

TRWM 项目从 jQuery 到 SolidJS 的重写整体质量**良好**，核心功能覆盖完整，架构设计合理。但在以下方面存在需要关注的问题：

- **功能覆盖**：24 个 RPC 方法中 23 个已实现，1 个缺失
- **国际化**：基本框架完善，但存在 40+ 处硬编码英文和 2 个缺失翻译键
- **UI/UX**：上下文菜单视口检测尺寸不匹配
- **性能**：存在运行时性能瓶颈
- **代码质量**：71 处 `any` 类型，缺少 ErrorBoundary，多处未处理 Promise 拒绝
- **测试**：零测试覆盖，无测试基础设施
- **无障碍**：模态框缺少焦点管理，ARIA 属性严重不足

#### 问题 1.1-A：`session_close` 完全缺失
- **等级**：Medium
- **位置**：全项目无任何调用，`LEGACY_METHOD_MAP` 中也无注册
- **描述**：用户无法从 Web UI 远程关闭 Transmission 守护进程
- **修复建议**：在 `rpc-legacy.ts` 的 `LEGACY_METHOD_MAP` 中添加 `session_close: 'session-close'`，并在设置页面提供"关闭 Transmission"按钮（需二次确认）

#### 问题 1.1-B：`alt_speed_enabled` 保存时硬编码为 `false`
- **等级**：**Critical**
- **位置**：[GlobalConfigModal.tsx](file:///home/qq/code/trwm/src/components/Modals/GlobalConfigModal.tsx#L176)
- **描述**：`handleSave` 函数中 `alt_speed_enabled: false`，每次保存全局设置都会强制关闭备用速度模式，覆盖用户通过状态栏启用的备用速度
- **根因**：开发者可能认为备用速度是临时状态，不应在设置中持久化，但实际上 `session_set` 会立即生效
- **修复建议**：改为 `alt_speed_enabled: session.alt_speed_enabled`，保持当前状态不变

#### 问题 1.1-C：`torrent_add` 缺少 `cookies` 参数
- **等级**：Medium
- **位置**：[AddTorrentModal.tsx](file:///home/qq/code/trwm/src/components/Modals/AddTorrentModal.tsx#L98-L110)
- **描述**：无法为需要 HTTP 认证的种子链接提供 Cookie，对私有 tracker 场景影响较大
- **修复建议**：在添加种子对话框中增加可选的 Cookie 输入字段
